# Images

This directory stores image assets used by Bayeishuui, including project artwork, diagrams, screenshots, icons, and other visual resources.

## Guidelines

- Use descriptive, lowercase filenames with hyphens where practical.
- Prefer SVG for scalable logos and diagrams, and PNG or JPEG/WebP for raster images as appropriate.
- Keep image references relative to the repository so they work across clones and branches.
- Add attribution and licensing information for third-party assets.
- Update the relevant documentation when adding or replacing an image.
