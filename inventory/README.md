# Inventory: Original Terminal Prototype

This directory preserves the original Python terminal-adventure game from Bayeishuui's first prototype. It is kept separate from the planned martial-arts fighting game.

## Run

From the repository root:

```sh
python3 inventory/bayeshuui.py
```

Or use `make run` from the repository root.

## Requirements

- Python 3.10+
- Linux/POSIX terminal with ANSI support
- Interactive terminal input
- Standard library only

The game is an earlier turn-based cave adventure, not the planned third-person martial-arts game. The current direction and next implementation steps are documented in the repository-root `MARTIAL_ARTS_DESIGN.md`.
